# 포챔스 오버레이 (0.1.0 뼈대) — 실행 방법

에뮬레이터 무관 PC 오버레이. 게임 창을 주기 캡처해서 선출/배틀 화면을 자동 감지하고,
게임 위 반투명 HUD에 **역할 추정**(선출) / **선공 판정 + 확정 타수**(배틀)를 표시합니다.

## 설치 (최초 1회)
1. [Node.js LTS](https://nodejs.org/ko) 설치
2. 이 폴더에서 터미널 열고:
```bash
npm install
npm start
```

## 사용
1. **설정 창**에서 캡처할 게임 창 선택 (에뮬레이터 창은 초록 표시로 자동 인식 — BlueStacks/LDPlayer/Nox/MuMu 등 무관)
2. 배틀 분석용 **내 포켓몬** 검색·선택 (지금은 픽률 1위 세트 가정 — 내 실제 세트 연동은 추후)
3. 게임 진행 — 선출/배틀 화면이 뜨면 자동 인식되어 HUD 갱신

| 단축키 | 동작 |
|---|---|
| Alt+O | 오버레이 표시/숨김 |
| Alt+I | 오버레이 조작 모드 (HUD 드래그/클릭) ↔ 클릭 통과 |
| Alt+R | 강제 재인식 |

## 현재 상태 (뼈대)
- ✅ 창 선택형 캡처 (에뮬레이터 무관) · 투명 클릭스루 오버레이 · 핫키
- ✅ 화면 자동 분류 (선출/배틀/기타) — 합성 프레임 테스트 통과, 실화면 튜닝 대기
- ✅ 선출: 스프라이트 매칭 → 역할 추정 HUD
- ✅ 배틀: 상대 이름 OCR → 선공 시나리오 + 양방향 확1/확2 HUD
- ⏳ 실화면(BlueStacks 등) 검증·좌표 튜닝 필요 — 문제 시 Alt+R로 강제 재인식 후 제보
- ⏳ 내 파티 실제 세트 연동 (기존 계산기의 파티 등록 재사용 예정)

## 구조 (안드로이드 이식 대비)
```
electron/   ← 셸 (PC 전용: 창 캡처·오버레이 창·핫키) — 안드로이드에서 Kotlin으로 대체
shared/     ← screen-classifier.js (순수 로직)
engine.js   ← 계산 엔진 (순수 로직)
analyzer.js ← 선공/타수/역할 추정 (순수 로직)
matcher.js  ← 스프라이트 매칭 (순수 로직)
data.js, spriteindex.js, assets/ ← 데이터
```
순수 로직 레이어는 안드로이드 WebView에 그대로 실립니다.
